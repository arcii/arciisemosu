# Math Archive v0.1

## 실행
정적 파일이라 GitHub Pages에 그대로 올릴 수 있습니다.
로컬에서 열 경우 fetch 때문에 일부 브라우저에서 JSON 로딩이 막힐 수 있으므로 VS Code Live Server 등을 권장합니다.

## 현재 포함
- 최근 평가원 시험 카탈로그
- 공식 EBSi 자료 링크
- 문제은행 필터
- 난이도/배점/단원 필터
- 문제 풀이 UI
- 정답/오답 처리
- localStorage 오답노트/풀이 통계
- 반응형 UI

## 중요한 설계 결정
실제 기출 원문은 우선 공식 자료 링크를 통해 제공하고, 문제은행 엔진은 독립된 데이터(JSON)로 만들었습니다.
따라서 향후 합법적으로 확보한 문제 데이터셋을 `data/questions.json`으로 교체/확장하면 UI를 다시 만들 필요가 없습니다.

## 다음 단계
1. 실제 기출 문제 데이터셋 구축
2. 문제별 교육과정/단원/세부개념 태깅
3. 공식 오답률/정답률 데이터 연결
4. 시험 전체 풀기 모드
5. 사용자별 통계
6. 로그인/클라우드 저장이 필요하면 Supabase 등 백엔드 추가
