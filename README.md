# 세모수 v0.3

실제 사용자가 제공한 수학 문제지/정답 및 풀이 PDF에서 문항별 이미지를 추출해 정적 웹사이트에 포함한 버전입니다.

## 구조
- `index.html` : 사이트
- `css/style.css` : UI
- `js/app.js` : 기능
- `data/questions.json` : 230개 문항 메타데이터/정답/문제 이미지 경로
- `data/solutions.json` : 230개 문항별 해설 이미지 경로
- `assets/problems/` : 문항별 문제 이미지
- `assets/solutions/` : 문항별 해설 이미지

## 현재 수록
- 2026학년도 6월 모의평가
- 2026학년도 9월 모의평가
- 2026학년도 대학수학능력시험
- 2027학년도 6월 모의평가
- 2027학년도 9월 모의평가

각 시험은 공통 22문항 + 선택과목(확률과 통계/미적분/기하) 각 8문항으로 구성됩니다.

## 핵심 동작
- 사용자가 PDF를 다시 업로드할 필요 없음
- 문항을 누르면 해당 문항 이미지만 표시
- 답 제출 전 해설 이미지의 URL/이미지를 DOM에 넣지 않음
- 답 제출 후 해당 문항의 해설 이미지만 표시
- 오답노트/풀이기록은 localStorage 사용
- GitHub Pages 프로젝트 사이트에서도 작동하도록 모든 정적 경로를 `./` 상대경로로 사용

## GitHub Pages
저장소 루트에 `index.html`, `css`, `js`, `data`, `assets`를 그대로 올리면 됩니다.
`assets` 폴더를 다른 위치로 옮기거나 중첩시키면 안 됩니다.

## 주의
이 버전의 문항 이미지는 사용자가 제공한 원본 자료에서 추출한 것입니다. 공개 GitHub Pages로 배포하기 전 원자료의 공개/재배포 조건을 확인하세요.
