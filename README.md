# 세모수 — 수학 기출 아카이브 v0.2

GitHub Pages에 바로 올릴 수 있는 정적 웹사이트입니다. `https://arcii.github.io/arciisemosu/`처럼 저장소 하위 경로에 배포하는 경우를 고려해 파일 참조를 상대 경로(`./...`)로 작성했습니다.

## 이번 버전
- 2026학년도 6월·9월 모의평가, 2026학년도 수능, 2027학년도 6월·9월 모의평가의 공통 수학 22문항: 총 110개 문항 메타데이터
- 업로드된 해설 PDF의 정답표를 바탕으로 객관식·단답형 정답 등록
- 시험별 공통 22문항 연속 풀이, 시험·단원·난이도·배점 필터, 고난도 문항 모아 풀기
- 오답노트, 누적 풀이 기록, 정답률
- 문제지·해설 PDF를 브라우저에서 로컬로 불러오는 기능
- 로딩 오류 안내와 GitHub Pages 하위 경로 호환

## 배포
1. ZIP을 압축 해제합니다.
2. `index.html`, `css/`, `js/`, `data/`, `README.md`를 저장소 루트에 업로드합니다. `index.html`을 하위 폴더 안에 넣지 마세요.
3. GitHub 저장소 **Settings → Pages**에서 `Deploy from a branch`, `main`, `/(root)`를 선택합니다.
4. 배포 후 `https://arcii.github.io/arciisemosu/`를 엽니다. 변경 사항 반영까지 몇 분 걸릴 수 있습니다.

## PDF 연결
1. `math_semosu.zip`을 PC에서 압축 해제합니다.
2. 사이트의 **시험별** 메뉴로 이동합니다.
3. 각 시험 카드에서 `math_mun_YYMM.pdf`를 **문제지 PDF**, `math_hsj_YYMM.pdf`를 **해설지 PDF**로 선택합니다.
4. 파일은 IndexedDB를 통해 현재 브라우저에 저장되며 서버로 전송되지 않습니다. 같은 브라우저에서는 다시 선택하지 않아도 됩니다. 브라우저 데이터를 지우면 PDF도 삭제됩니다.

문제지 PDF는 한 페이지에 여러 문항이 실려 있으므로 문제 화면의 문항 번호와 페이지 번호를 함께 확인하세요. 해설 PDF 페이지 위치는 PDF 판본에 따라 일부 차이가 있을 수 있습니다.

## 범위 및 주의
- 현재는 **공통 수학 1~22번**만 등록했습니다. 선택과목(확률과 통계·미적분·기하) 23~30번은 다음 데이터 확장 단계입니다.
- 난이도와 단원은 출제의도 텍스트를 이용한 초기 분류이며 공식 난이도/단원 분류나 공식 오답률 통계가 아닙니다.
- PDF 파일은 이 프로젝트에 포함하지 않았습니다. 사용자가 보유한 PDF를 브라우저에서 직접 선택해 열도록 했습니다. GitHub Pages 사이트는 공개 웹사이트이므로, 문제지·해설지 PDF 자체를 저장소에 올리기 전에는 해당 자료의 이용 조건을 확인하세요.
- 문제·정답 자료의 권리는 원 출처에 있습니다. 공식 자료 링크는 EBSi 기출 자료실로 연결됩니다.
